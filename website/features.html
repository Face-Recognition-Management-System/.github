功能模組

13 項模組，
核心內建 · 加值彈選。

FRM System 將功能拆分為「核心模組」與「加值模組」兩大類。 核心模組標準內建、開箱即用；加值模組可依需求單獨授權， 讓您只為實際使用的功能付費，隨業務成長隨時擴充。

核心模組 · 標準內建

6 項核心模組。

所有 FRM System 部署皆內建以下核心模組，無需額外授權即可使用。

M.01
核心

狀態監控

提供即時人臉辨識事件流、門禁狀態與裝置在線情形，所有現場動態一目了然。

  • 門禁狀態看板與裝置健康監測
  • 即時辨識事件流，含人員資料與截圖
  • 大屏監控模式（深色版）
M.02
核心

人員管理

建立與維護完整人員資料庫，包含人臉照片、識別卡片、部門與群組關係。

  • 批次匯入與匯出
  • 人臉照片建模與重建
  • 群組化權限指派
M.03
核心

門禁管理

統一管理門禁裝置、通行時段與群組通行規則，輕鬆配發到任一終端。

  • 裝置綁定與群組配發
  • 通行時段設定（每日 / 每週）
  • 規則異動即時下發
M.04
核心

事件中心

儲存所有辨識事件與進出記錄，並提供高效查詢與影像截圖回放。

  • 多維度條件查詢（時間 / 人員 / 裝置）
  • 截圖與原圖檢視
  • 事件匯出（CSV / Excel）
M.05
核心

告警通知

定義告警規則與通知群組，重要事件第一時間推送到指定的接收者。

  • 告警群組與成員設定
  • 規則化觸發條件
  • 多通道通知
M.06
核心

維護與管理

設備管理、系統紀錄、系統設定，以及帳號與權限管理皆內建於同一後台。

  • 設備管理與系統紀錄查詢
  • 帳號 / 群組 / 權限細粒度設定
  • 支援 Active Directory 整合

加值模組 · 依需求授權

7 項加值模組。

加值模組可獨立購買授權，讓您依場域與業務需求彈性配置， 無需重新部署即可啟用。

L.01
需授權

平台考勤模組

依據辨識事件自動計算上下班、加班與遲到早退，產生班別報表，省去人工統計時間。

  • 班別設定與例外規則
  • 月份 / 部門 / 個人報表
  • 多項目自動計算與彙整
L.02
需授權

會議預約模組

會議室排程預約 + 人臉自動簽到 + 出席紀錄，讓會議室使用更有條理。

  • 會議室預約行事曆
  • 與會者管理與通知
  • 人臉自動簽到與出席統計
L.03
需授權

工地管理模組

專為工地與廠區設計的進出管理、廠商人員管控與 Dashboard 大屏監控。

  • Dashboard 大屏即時統計
  • 進出報表與廠商人員管控
  • 專屬深色監控介面
L.04
需授權

異地資料庫模組

提供標準資料庫推送介面，將 FRM 的辨識資料、事件記錄等定向送出， 由客戶開發團隊依文件自行串接至指定的異地資料庫，掌握所有資料流向。

  • 提供推送介面與資料欄位文件
  • 由客戶端自行開發接收端整合
  • 資料庫類型與欄位對應由貴方主導
L.05
需授權

異地 API 模組

以 HTTP / REST 形式對外推送辨識事件， 提供 API 規格文件供客戶開發團隊接入既有的人資、ERP 或門禁系統。

  • RESTful 事件推送介面
  • 提供 API 規格與資料格式文件
  • 由客戶端自行開發接收與後續處理
L.06
需授權

自動匯出模組

定時自動將辨識資料匯出為 TXT 檔案至指定路徑，方便對接既有的批次處理流程。

  • 排程匯出設定
  • 欄位與格式自訂
  • 檔案路徑彈性配置
L.07
需授權

Deltapath 電話告警模組

重要事件透過 Deltapath 通訊系統發出電話告警，讓關鍵訊息不漏接。

  • 對接 Deltapath 通訊平台
  • 緊急事件電話通知
  • 多接收者派發
